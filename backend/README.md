# バックエンド環境セットアップガイド

## 概要
Express を用いた Todo アプリケーションの REST API サーバーです。ローカル環境でのセットアップと実行方法をまとめています。

## 前提条件
- Node.js 18 以上を推奨
- npm が利用可能であること

## セットアップ手順
1. 依存パッケージをインストールします。
   ```bash
   npm install
   ```
2. 必要に応じて `.env` を作成し、環境変数を設定します。サーバーポートを変更する場合は `PORT` を指定してください。

## 開発サーバーの起動
API サーバーを起動するには次のコマンドを実行します。
```bash
npm start
```
デフォルトでは `http://localhost:3001` でサーバーが待ち受けます。ポート番号は `PORT` 環境変数で上書きできます。

## テストの実行
Jest を使用した単体テストを実行するには以下を実行します。
```bash
npm test
```
テスト環境では自動で `NODE_ENV=test` が設定されます。失敗したテストがある場合はコンソールの結果を確認してください。

## ディレクトリ構成
- `src/app.js`: Express アプリケーションの初期化処理
- `src/routes/`: ルーティング定義
- `src/controllers/`: リクエスト処理ロジック
- `src/services/`: ビジネスロジック
- `tests/`: Jest によるテストコード

## トラブルシューティング
- 依存パッケージに問題がある場合は `rm -rf node_modules package-lock.json && npm install` を試してください。
- ポート競合が発生した際は `PORT=4000 npm start` のように環境変数で変更できます。
